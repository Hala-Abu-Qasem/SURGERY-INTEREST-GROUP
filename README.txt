To run locally:
1. Open the folder in VS Code.
2. Open index.html.
3. Right-click -> Open with Live Server / Show Preview, or double-click index.html.
4. Replace TBC/placeholder content as details are confirmed.

Before public launch:
- Add official logo/photos.
- Replace Person X/Person Y.
- Add official social links and email.
- Connect the contact form to a real form/email service.
- Add real event dates and recaps.
- Review all copy and approvals with SIG/AlFaisal University.
